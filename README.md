# FoodShare

FoodShare is a food donation website that helps connect people who have extra food with NGOs that can collect and distribute it.

The idea is simple — instead of wasting extra food, a donor can add the food details on FoodShare and NGOs can view available donations and accept them.

## What it does

### For Donors
- Register and login
- Add a food donation
- Add food quantity, category, dates, pickup address and contact number
- Upload a food image
- See submitted donations
- Track donation status
- See their donation impact

### For NGOs
- Register as an NGO
- View available food donations
- Open donation details
- View the uploaded food image
- Accept donations
- Complete accepted donations

### Find NGOs
The website also has a Find NGOs section where users can:
- Search registered NGOs
- See NGO name and location
- See contact person and contact details
- See NGO ID
- Check their donation contribution
- Contact the NGO through email or phone

## How it works

Donor adds food
→ Donation becomes available
→ NGO views it
→ NGO accepts it
→ Donation is completed
